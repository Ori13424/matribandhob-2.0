# Matri Bandhob V2.1 - Expansion Plan (Social & Admin)

## Objective
To expand the platform with a social community for mothers, enhanced medical profiles for AI context, and a robust Super Admin panel for system management.

---

## Module A: Mother Dashboard & Community (Social)

### 1. Community Forum (`/src/app/patient/community`)
**Goal:** Create a safe space for mothers to share stories, ask questions, and interact.

**Architecture:**
- **Route:** `src/app/patient/community/page.tsx`
- **Firestore Schema:**
    - **Collection:** `posts`
    - **Document:**
        ```typescript
        {
          id: string;
          authorId: string;
          authorName: string;
          authorRole: 'mother' | 'doctor';
          content: string;
          tags: string[]; // e.g., "Pregnancy", "Nutrition", "Mental Health"
          likes: number; // Counter
          likedBy: string[]; // Array of user IDs
          commentCount: number;
          timestamp: Timestamp;
        }
        ```
    - **Sub-Collection:** `posts/{postId}/comments`
        ```typescript
        {
          id: string;
          authorId: string;
          authorName: string;
          content: string;
          timestamp: Timestamp;
        }
        ```

**UI Components:**
- **PostFeed:** Infinite scroll list of posts.
- **CreatePostWidget:** Simple textarea with tag selection.
- **PostCard:** Displays post content, like button, and "View Comments" toggle.
- **CommentSection:** Nested component to load/add comments.

### 2. Enhanced Medical Profile (`/src/app/patient/profile`)
**Goal:** Capture detailed medical history context for the AI Chatbot and Doctors.

**Changes:**
- Update `src/app/patient/profile/page.tsx`:
    - Add **"Medical History"** section in the Settings/Profile view.
    - **New Fields:**
        - `allergies` (Text/Tags)
        - `pastComplications` (Text Area)
        - `currentMedications` (Dynamic List)
        - `bloodPressureHistory` (Visualized via existing Vitals, but editable in profile?) -> *Keep strictly in Vitals log, but show summary here.*
- **Data Sync:**
    - Ensure `usePatientProfile` hook pulls this new data.
    - Update `AIService` system prompt to include `allergies` and `medications` in the context window.

### 3. Vitals Graph Integration (Doctor Dashboard)
**Goal:** Replace dummy data with real population health trends.

**Action:**
- Update `VitalsGraphWidget.tsx` to accept `patients: Patient[]` prop.
- **Logic:**
    - Iterate through all patients.
    - Group `vitalHistory` logs by day (Mon, Tue, Wed...).
    - Calculate **Average Systolic BP**, **Average Diastolic BP**, and **Average Blood Sugar** for each day.
    - Feed this aggregated data into the `Recharts` graph.

## Module B: Super Admin Panel (`/src/app/admin`)

### 1. Admin Portal Layout
**Goal:** A protected, high-level control center.

**Architecture:**
- **Route:** `src/app/admin/page.tsx` (Dashboard) & `src/app/admin/users/page.tsx` (User Management).
- **Security (RBAC):**
    - Create `AdminGuard` component or check `user.role === 'admin'` in `layout.tsx`.
    - If unauthorized, redirect to `/login`.

### 2. Unified User Management
**Features:**
- **Data Table:** Fetch all users from Firestore `users` collection.
- **Filters:** Tabs for `All`, `Mothers`, `Doctors`, `Drivers`.
- **Actions:**
    - **Verify:** Toggle `isVerified` boolean (critical for Doctors).
    - **Suspend:** Toggle `status: 'suspended'`.
    - **Delete:** Call Server Action to remove from Firebase Auth & Firestore.

### 3. System Health & Debugging
**Features:**
- **Debug Console:**
    - Simple read-only view of a new `system_logs` collection (optional, or just console logs for now).
- **Test Triggers:**
    - Button: "Test SOS Alert" -> Creates a dummy SOS alert to verifying Driver Dispatch logic.
    - Button: "Test Broadcast" -> Sends a test notification to all users.

## Module C: "Send Advisory" Feature (Doctor Dashboard)

**Goal:** Allow doctors to send broadcast health tips or alerts.

**Implementation:**
- **UI:** Connect the existing "Send Advisory" button in `DoctorDashboard`.
- **Logic:**
    - Open a Modal: "Write Advisory Message".
    - On Submit: Create a document in `notifications` (fan-out) or a single `announcements` document.
    - **Preferred:** Create `announcements` collection.
        ```typescript
        {
          title: string;
          message: string;
          audience: 'all' | 'mothers' | 'drivers';
          authorId: string;
          timestamp: Timestamp;
        }
        ```
    - Patient Dashboard listens to `announcements` and shows a Toast or Banner.
